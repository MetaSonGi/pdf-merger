# 📄 PDF 합치기 | PDF Merger

> Merge multiple PDFs in order

---

여러 PDF를 순서대로 하나로 합치는 웹앱.


## 기능

- 📄 여러 PDF 일괄 추가 (드래그 앤 드롭)
- 🔢 페이지 수 표시, ↑↓ 순서 변경, 삭제
- 📚 원클릭 합치기 → 파일명으로 다운로드

## 기술

- pdf-lib (CDN) + Vanilla JS
- 100% 클라이언트 사이드 (서버 전송 없음)
